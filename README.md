# Electricity Consumption Analysis

## Project Overview
Electricity Consumption Analysis is a data analytics project developed using Python in Google Colab. The project analyzes household electricity consumption data to identify usage patterns, trends and insights over time.

## Objectives
- Analyze household electricity consumption.
- Identify daily and monthly electricity usage patterns.
- Find the highest and lowest consumption days.
- Understand electricity usage trends.
- Present insights using data visualization.

## Dataset
The project uses the Individual Household Electric Power Consumption dataset.

Dataset contains:
- Date
- Time
- Global Active Power
- Global Reactive Power
- Voltage
- Global Intensity
- Sub Metering 1
- Sub Metering 2
- Sub Metering 3

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Data Analysis
- Data Visualization

## Data Analysis
- Dataset inspection and preprocessing.
- Missing value identification and handling.
- Daily electricity consumption analysis.
- Monthly electricity consumption analysis.
- Identification of maximum and minimum consumption.
- Visualization of electricity usage patterns.

## Key Findings
- Average daily electricity consumption: 26.02 kWh.
- Highest daily consumption: 79.56 kWh.
- Lowest daily consumption: 0.24 kWh.
- Highest monthly consumption: December 2007.
- Lowest monthly consumption: August 2008.
